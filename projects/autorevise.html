AutoRevise-VLM

A vision-grounded defense framework for spotting adversarial attacks against Vision-Language Models.

Overview

AutoRevise-VLM focuses on building robust evaluation and detection mechanisms for modern vision-language systems. The goal was to assess how well multimodal models behave under adversarial perturbations and to provide a structured defense-oriented workflow.

Core Technologies

PyTorchGPT-4oCLIPBLIP-2Flask

Contribution

I handled the end-to-end development of the model workflow, API serving, and evaluation logic using Python and deep learning tools.

Highlights

  • Implemented transformer-based evaluation pipelines for VLM robustness.
  • Integrated a real-time inference API with Flask for testing and deployment.
  • Used performance metrics like accuracy, precision, recall, and semantic similarity to monitor model behavior.
