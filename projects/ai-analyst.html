AI Analyst for Startup Evaluation

A hybrid LLM + ML system for analyzing startup materials and generating explainable investment insights.

Overview

The system ingests PDFs and public data, builds a knowledge base with embeddings, and combines ML scoring with RAG-driven LLM summaries for startup evaluation.

Core Technologies

PythonFAISSStreamlitML

Architecture

  • PDF ingestion with OCR fallback
  • Embedding and chunking via SentenceTransformers
  • Hybrid decision: ML score + LLM evidence
  • Interactive Streamlit dashboard
