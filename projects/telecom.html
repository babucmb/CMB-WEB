Autonomous Telecom Fault Management System

A multi-agent AI system for autonomous fault detection, root-cause analysis, and real-time network alerting.

Overview

This project reimagines telecom operations by turning incident handling into an agent-driven workflow. Instead of relying only on manual review, the system uses LLMs, RAG, and orchestration to reason, retrieve knowledge, and recommend actions for network faults.

Problem

Telecom teams often face high-volume alerts and fragmented knowledge sources. The manual triage process is slow, error-prone, and difficult to scale under real-time pressure.

Solution

I designed a multi-agent system using Google ADK and CrewAI, where different agents collaborate for reasoning, evidence retrieval, and response generation.

Core Stack

PythonGoogle ADKCrewAILLMRAGFAISSStreamlit

What I Built

  • Multi-agent orchestration for autonomous fault detection and investigation.
  • RAG-based retrieval over telecom knowledge and historical incident data.
  • Interactive monitoring dashboard for operational visibility and decision support.

Impact

The system demonstrates how enterprise AI can move from static automation to intelligent decision support by combining LLM reasoning, vector search, and agent collaboration.
