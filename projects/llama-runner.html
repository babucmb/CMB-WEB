LLaMA-2 CPU Runner

An optimized workflow to run LLaMA 2 inference on CPU using llama.cpp and GGUF quantized models.

Overview

This project enables LLaMA 2 to run efficiently without a GPU by using llama.cpp and quantized GGUF models. It is designed for local machines and Google Colab environments.

Features

  • CPU-only LLaMA 2 inference
  • llama.cpp integration for fast local inference
  • GGUF quantized model support for low-memory usage
  • Works on Google Colab and local environments

Quickstart

Install dependencies and use a GGUF model for optimized performance:

pip install llama-cpp-python

Repository

Full code examples, model setup, and performance tips are available on GitHub.
