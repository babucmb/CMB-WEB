# AI Engineer Portfolio

This portfolio is designed to present Mahesh Babu as a serious AI Engineer and GenAI developer with enterprise-oriented experience in LLM systems, RAG, multi-agent AI, and machine learning.

## Structure

- index.html — main landing page
- style.css — full dark AI-themed styling
- script.js — typing effect and GitHub stats loading
- projects/ — detailed project pages
- assets/ — illustrations and resume download

## Deploy on GitHub Pages

1. Push this folder to your GitHub repository.
2. Open the repository settings.
3. Enable GitHub Pages from the main branch.
4. Your site will be available at your GitHub Pages URL.
